# proyecto_analisis_emisor
Este proyecto desarrolla un análisis financiero comparativo entre LULO BANK S.A. y el sistema financiero colombiano, con el objetivo de evaluar la viabilidad de incluir al emisor como alternativa de inversión dentro de un portafolio diversificado. El análisis se basa en información financiera histórica consolidada.

# Objetivo

Evaluar el perfil financiero, el nivel de riesgo y la capacidad de generación de valor de LULO BANK S.A., comparándolo con el sistema financiero colombiano, para soportar una recomendación informada sobre su inclusión o no dentro de un portafolio de inversión.

# Alcance del análisis

Consolidación automática de archivos Excel mensuales.
Estructuración jerárquica de la información financiera (Rubro, Subrubro y Detalle).
Cálculo de indicadores clave:
Activos totales y participación en el sistema.
Endeudamiento (Pasivo / Activo).
Rentabilidad sobre el patrimonio (ROE).
Comparación año a año entre LULO BANK y el sistema financiero.
Generación de visualizaciones para soporte de análisis y toma de decisiones.
Elaboración de conclusiones orientadas a inversión y diversificación de portafolio.
